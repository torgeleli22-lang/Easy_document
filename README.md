# 쉬운말

어려운 문서를 사진 한 장으로 올리면, 쉬운 말로 풀어주고 · 해야 할 일과 기한을 정리하고 · 주의할 점을 짚어주는 서비스입니다.
점검한 문서를 보관하면 기한이 **일정 달력**에 모이고, 기한이 없는 증명서·설명서도 **보관함**에서 낱말 하나로 다시 찾을 수 있습니다.
일정이 계속 쌓이는 직장인과 대학 조교를 염두에 두었습니다.

## 화면

| 주소 | 하는 일 |
| --- | --- |
| `#/` 점검하기 | 사진·PDF·글을 맡깁니다 |
| `#/analysis` | 진행 상황. 문서 종류가 확실하지 않으면 "이 문서가 무엇인가요?"라고 묻고, 고르면 그 종류로 다시 점검합니다 |
| `#/result` | 원본과 풀이를 나란히 봅니다. 보관함 저장, 휴대폰 달력(.ics) 추가, 워드 내려받기, 가족에게 보내기 |
| `#/schedule` 일정 | 보관한 문서의 기한을 임박순 목록과 월 달력으로. 완료 체크, 할 일 직접 추가, 전체 .ics 내보내기 |
| `#/archive` 보관함 | 낱말 검색, "최근 7일/30일 안에 본 것" 걸러보기, 기한 있는/참고용 문서 구분, 백업 내려받기·불러오기 |
| `#/archive/:id` | 보관한 문서 하나. 열 때마다 "마지막으로 본 날"이 갱신됩니다 |

기획서: `docs/` (예정) · 구성안: 프로젝트 파일의 `쉬운말-저장소-구성안.md`

## 구성

| 경로 | 내용 |
| --- | --- |
| `frontend/` | React + Vite. GitHub Pages로 배포되는 정적 화면 |
| `shared/schemas/` | 분석 결과 스키마. 프런트엔드와 백엔드가 함께 쓰는 단일 출처 |
| `shared/pii.ts` | 개인 식별 정보 가리기. 백엔드와 보관함 저장이 함께 씁니다 |
| `backend/` | AWS Lambda 분석 함수. Claude API로 문서를 읽어 결과 스키마대로 돌려줍니다 → `backend/README.md` |
| `infra/` | IaC (예정, 도구 미정) |
| `eval/` | 평가 세트와 지표 측정 (예정) |

## 개발

```bash
cd frontend
npm install
npm run dev
```

`VITE_API_URL`이 비어 있으면 목업 데이터로 동작합니다. 첫 화면의 "예시 문서로 해보기"를 누르면
학과 공문(기한이 오늘 기준으로 잡힘)이나 근로계약서를 붙여넣어 흐름을 끝까지 볼 수 있고,
그 밖의 아무 글을 넣으면 확신도가 낮게 나와 문서 종류 질문 화면을 확인할 수 있습니다.

실제 AI로 점검하려면 `backend/`를 띄우고 `frontend/.env.local`에 주소를 적습니다.

```bash
cd backend
npm install
ANTHROPIC_API_KEY=... npm run dev
```

```bash
echo "VITE_API_URL=http://localhost:8787" > frontend/.env.local
```

결과 화면에서 워드(.docx) 파일을 내려받을 수 있습니다. 원본을 문서에 싣고
원문 문단 바로 아래에 설명 박스를 붙이는 구조이며, 파일은 전부 브라우저 안에서
만들어집니다. 원본 서식과 레이아웃은 보존되지 않습니다.

- `npm run build` — 타입 검사 후 빌드
- `npm run typecheck` — 타입 검사만

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 빌드해서 GitHub Pages로 올립니다.
주소는 `https://torgeleli22-lang.github.io/Easy_document/` 이고,
그래서 `vite.config.ts`의 `base`가 `/Easy_document/`로 잡혀 있습니다.

## 원칙

- **서버 무저장**: 문서를 서버에 저장하지 않습니다. 분석 함수는 메모리에서만 다루고 본문을 로그에 남기지 않습니다.
  공유·다운로드·달력 파일은 브라우저 안에서 만듭니다.
- **보관은 내 기기에만**: 사용자가 "보관함에 저장"을 누른 문서만 이 브라우저의 IndexedDB에 남습니다.
  원본 사진은 남기지 않고 풀이와 옮겨 적은 글만 남기며, 브라우저 데이터를 지우면 함께 사라집니다(백업 파일로 옮길 수 있음).
- **개인정보는 가려서**: 주민등록번호·외국인등록번호, 전화번호, 카드 번호는 저장하지 않습니다. AI에게 가려서 옮겨 적게 하고,
  백엔드 응답 직전과 보관함 저장 직전에 `shared/pii.ts`로 한 번 더 가립니다. 계좌번호는 날짜·금액과 헷갈리기 쉬워 가리지 않습니다.
- **큰 글씨가 기본**: 접근성 토큰은 `frontend/src/styles/tokens.css`에 모아두었습니다.
- **근거 표시**: 모든 항목에 원문 인용을 붙이고, 문서에 적힌 내용과 일반 안내를 구분합니다.
